## 采用的视觉规则

- 暖灰奶油底色 `#ece7e0`；深色正文 `#383b33`、次级正文 `#6d685f`。
- 柔和浮雕：右下阴影 `8px 8px 18px #d6cfc6`、左上高光
  `-8px -8px 18px #fbf8f4`；输入与选中态使用相同方向的内凹阴影。
- 主要卡片圆角 20–22px；动作与次级控件 10–16px。
- 琥珀 `#df9d43` 用于主要动作与进度；叶绿 `#82a969` 用于来源和已配置状态；
  蓝色 `#7493b7` 用于用量与分析。可读文字采用对应较深色值，不直接用浅色装饰作正文。
- Poppins 提供标题与拉丁文字，中文沿用系统中文字体；Roboto Mono 用于调用量、
  费用与日期。字体在本机提供，不依赖第三方运行时字体请求。
- 用自绘一致线宽 SVG 表达桥、资料、搜索、分析与只读访问。

## 内容映射

| 原参考 | Bridge 工作台 |
| --- | --- |
| 房间卡片网格 | 问题输入、研究方式和已保存的任务卡片 |
| Home / Away / Night | 全部任务 / 待继续 / 已完成，实际筛选任务 |
| Quick Scenes | 记住约定 / 核对官方资料 / 分析调用，只填充输入，显式点击开始后运行 |
| 能源仪表栏 | 保存结果计算的进度、采用来源比例、已报告 Tokens 与费用 |
| Security 清单 | 凭据是否配置、模型分工配置、远程 MCP 配置 |
| 详情控制区 | 精确原句、来源快照、实际工具记录与调用账本 |

不添加无业务意义的温度或调光滑块。没有凭据、来源或用量时展示明确空态；
连接“已配置”只表明配置存在，不冒充模型调用成功。未知费用与 Tokens 不计为零。
进度按保存的检索/提取/网页/MCP/回答/分析结果计算；来源比例表示回答采用的来源占比，
不表示答案正确率、可信度或比赛分数。

## 实现与验收

沿用 Python + 静态 HTML/CSS/JavaScript。`dashboard-data.js` 提供同一份纯数据汇总与
任务筛选逻辑，浏览器按顺序加载；脚本作用域封装避免全局名称冲突。

本次新增 4 个消费契约先失败后通过：未知用量保留、零与部分费用报告、保存结果进度、
任务状态筛选。JavaScript 语法检查通过。没有运行旧回归套件。
浏览器实际完成场景填充、研究结果查看、任务筛选、引用展开及 1440/390 布局检查。

57 Tokens、0.000009 USD，与脚本化网关返回的账本一致；这些是本地样例，不能作为托管证据。
