# 退款重试与幂等约定

这是参赛演示用的虚构工程约定，不含真实客户、账户或支付记录。

同一退款业务使用稳定的业务键。网络重试可以重复传输请求，但同一业务只能产生一次实际退款效果。

本地缓存只能作为优化；幂等性需要由业务状态、持久化约束和外部接口的明确契约共同保证。

请求超时后先查询或核对原操作的状态，再决定如何继续。无法确认的费用和执行状态必须保留为未知。
