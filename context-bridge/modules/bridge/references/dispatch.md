# 仅用户明确要求创建新对话时读取

先检查当前宿主能力。确有 create_thread 工具时使用它；项目任务先 list_projects 确认项目，projectless 提供原目录绝对路径并验证访问。Claude Code 或其他环境没有该工具时，直接提供完整的可粘贴恢复提示，不能调用虚构工具或宣称已创建对话。只有跨宿主或环境问题时才读 [hosts.md](hosts.md)。新窗口界面不等于新上下文；不用继承完整历史的 fork 作为瘦身方案。新对话不自动复制目录、权限或进程。不得自动建 worktree。

创建提示含 task-id、包绝对路径、源端 task_id/snapshot_id、目录、scope、receiver claim 路径，要求使用已安装 context-bridge 的恢复分支。先确认源端停写和锁已转交；claim 只交给一个接收端。

工具创建成功后，在确有读取/等待工具时只读等待接收验证，确认正确包、回执与锁检查均成功。没有回执只能说“已创建，待接收验证”；仅提供恢复提示时说“迁移包已准备，待新会话接收”。额外跨对话消息遵守实际工具授权。

源端接管期间保持只读。新增用户修正时先让接收端停止续写（需要现有授权或用户协调），取回所有权后生成新版本再交接，不能让旧包继续执行。创建失败按 ownership 恢复。旧对话不自动归档；旧包只有按已授权的 retention 保留策略才能回收。
